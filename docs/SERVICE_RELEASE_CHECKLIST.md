# サービスを提供する前の確認事項

このリポジトリはソースの公開です。ここにチェック項目があることは、サービス運営が承認されたことを意味しません。

- メール受信・転送の事業に必要な届出と通信の秘密の管理を、管轄機関や専門家へ確認する。
- 個人情報の取得・保存・削除・通報対応、外部送信、運営者表示を実際の構成に合わせて整理する。
- Cloudflareと接続するメール・Push等の提供元の現行利用条件を確認する。
- 利用規約・プライバシーポリシー等の未記入箇所を埋め、専門家の確認が必要か判断する。
- 本番の秘密鍵を発行し、DEV_INJECTを無効化する。ローカル用のdev-secretは使わない。
- 保存期限・認証・レート制限・削除を、テスト用データで確認する。
- 他サービスの禁止する利用や認証回避を促す表示・運用をしない。

一次資料: [電気通信事業法](https://laws.e-gov.go.jp/law/359AC0000000086)、[個人情報保護委員会](https://www.ppc.go.jp/)、[Cloudflareの条件](https://www.cloudflare.com/terms/)。法的適用は提供内容・運用によって変わるため、ここでは結論を確定しない。
